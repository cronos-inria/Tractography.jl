This tutorial will introduce you to the functionalities for computing streamlines.

Basic use

In this example, we sample Nmc streamlines from a Model model.

using Tractographyconst TG = Tractographymodel = Model(Δt = 0.125f0,            foddata = FODData((@__DIR__) * "/../../examples/fod-FC.nii.gz"),            )Nmc = 10seeds = rand(Float32, 6, Nmc)alg = Probabilistic()streamlines, tract_length = sample(model, alg, seeds);size(streamlines)
(3, 1000, 10)

Step 1: Define a Model

We define a Tractography Markov Chain (Model) model as follows:

model = Model(Δt = 0.125f0,            foddata = FODData((@__DIR__) * "/../../examples/fod-FC.nii.gz"),            )

Step 2: Define the seeds

seeds is a 6 x Nmc matrix. Each column stores:

  • seeds[1:3, i]: initial position (x, y, z) in native space
  • seeds[4:6, i]: initial direction (u1, u2, u3)

Optimal use

When computing multiple batches for the same model, it is more efficient to precompute a cache once and reuse it.

model = Model(Δt = 0.125f0,            foddata = FODData((@__DIR__) * "/../../examples/fod-FC.nii.gz"),            )Nmc = 10seeds = rand(Float32, 6, Nmc)streamlines = zeros(Float32, 3, 20, Nmc)tract_length = zeros(UInt32, Nmc)alg = Probabilistic()cache = TG.init(model, alg)# this can be called repeatedly after updating seeds for exampleTG.sample!(streamlines, tract_length, model, cache, alg, seeds);size(streamlines)
(3, 20, 10)
